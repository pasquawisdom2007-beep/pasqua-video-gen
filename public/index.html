How It Works

Three steps. No setup. No credit card. Just an API call.

01
🖼️
SEND IMAGE + PROMPT
POST your image file and a text prompt describing the motion. "Person walking through rainy Tokyo streets at night." That's all you need.
02
⚡
AI GENERATES THE VIDEO
Your request gets routed to CogVideoX-5B running on HuggingFace Spaces. The model animates your image with cinematic motion. Estimated time: 2–5 minutes.
03
🎬
DOWNLOAD YOUR VIDEO
Poll the status endpoint until the video is ready. Then hit the download endpoint — you get a full MP4 back. Stream it, forward it, send it on WhatsApp.

Available Models

Three open-source models. Each optimized for different use cases. All free.

CogVideoX-5B
The flagship model. Best cinematic quality, complex motion, realistic lighting and environment animation. The one that makes people ask "how is this possible."
Quality

Stable Video Diffusion
Fast image-to-video animation. Great for smooth motion effects, object movement, and camera pans. Best when you want speed over complexity.

AnimateDiff
Stylized smooth animation with consistent motion. Works best for artistic, illustrated, or stylized images. Great fallback when other models are busy.

API Documentation

All endpoints return JSON. Videos are streamed as MP4. No auth required for basic usage.

POST /api/generate Start video generation
FieldTypeDescription
image requiredFileImage file (jpg/png/webp, max 10MB)
prompt requiredStringMotion description. Be cinematic: "rain falls on the neon-lit streets as she walks away"
model optionalStringcogvideox | svd | animatediff (default: cogvideox)
steps optionalNumberInference steps 20–100 (default: 50). More = better quality, slower
seed optionalNumberRandom seed. -1 for random (default: -1)
GET /api/status/:job_id Poll generation status
StatusMeaningAction
pendingStringQueued, will start soon. Keep polling.
processingStringGenerating now. Poll every 8–10s.
doneStringvideo_url and download_url are in the response ✅
failedStringError in response. Retry with different model.
GET /api/video/:job_id Download video MP4
FeatureDetail
Formatvideo/mp4 with full range request support
AvailabilityAvailable 2 hours after generation (auto-cleanup)
HeadersX-Job-Id, X-Model-Used, X-Space-Used returned
GET /api/generate/models List available models
ReturnsDetail
models[]Array of available models with their HuggingFace spaces
defaultThe recommended default model key

Code Examples

Copy-paste ready. Works in any Node.js environment including WhatsApp bots.

whatsapp-bot-integration.js
// WhatsApp Bot — Image to Cinematic Video
const FormData = require('form-data');
const fs = require('fs');
const fetch = require('node-fetch');

const API_BASE = 'https://your-api.onrender.com';

async function imageToVideo(imagePath, prompt, model = 'cogvideox') {
  const form = new FormData();
  form.append('image', fs.createReadStream(imagePath));
  form.append('prompt', prompt);
  form.append('model', model);

  // 1. start generation
  const res = await fetch(`${API_BASE}/api/generate`, {
    method: 'POST', body: form
  });
  const { job_id } = await res.json();

  // 2. poll until done
  while (true) {
    await new Promise(r => setTimeout(r, 8000));
    const status = await fetch(`${API_BASE}/api/status/${job_id}`).then(r => r.json());

    if (status.status === 'done') return `${API_BASE}` + status.download_url;
    if (status.status === 'failed') throw new Error(status.error);
  }
}

// Usage in your bot command handler:
bot.on('message', async (msg) => {
  if (msg.hasMedia && msg.body.startsWith('.video ')) {
    const prompt = msg.body.slice(7);
    msg.reply('🎬 Generating your cinematic video...');
    const media = await msg.downloadMedia();
    const videoUrl = await imageToVideo(media, prompt);
    msg.reply(videoUrl);
  }
});
